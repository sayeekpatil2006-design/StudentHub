# StudentHub

An interactive student productivity & academic management dashboard — tasks, timetable, attendance, notes and a focus timer in one place. Built with HTML, CSS, and Vanilla JavaScript. Data is saved in your browser (localStorage).

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# visit http://localhost:8000
```

## Files

- `index.html` – landing page
- `dashboard.html` – dashboard (Overview, Tasks, Timetable, Attendance, Notes, Focus)
- `styles.css` – styles
- `app.js` – dashboard logic
